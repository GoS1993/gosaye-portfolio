# Gosaye Mulusew — Portfolio

A responsive, dark editorial-style portfolio focused on React, Node.js, and full-stack software development.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your real professional email.
- Add your GitHub and LinkedIn URLs if you want those links shown.
- Confirm the wording of your experience and projects so every claim reflects your actual work.
- If you have public project demos or repositories, replace the “Discuss this project” links with those URLs.

## Build for production

```bash
npm run build
```

The production site will be created in `dist/`. You can deploy it with Vercel, Netlify, or another static hosting provider.
